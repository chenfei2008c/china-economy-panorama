# 中国经济全景 · 交互仪表盘

以《经济学人》的编辑式视觉为参考：纸色背景、红色强调、衬线大标题、细分隔线、紧凑数据图。使用自己的“中国经济全景”标识。

## 打开

在仓库根目录运行：

```sh
python3 -m http.server 4178 --bind 127.0.0.1 --directory dashboard/dist
```

在浏览器打开 `http://127.0.0.1:4178/`。`dist/` 已包含可运行的完整静态页面与公开数据快照，无需 npm 或数据库。它需要 HTTP 服务读取相邻的 JSON 文件，不能仅双击 `index.html`。此命令只监听本机。

## 数据与解释边界

- 首页使用已核验的2025年数据样例。2025年12月末M2是时点存量同比；GDP是全年流量，比较时保留时间口径。
- 名义GDP增长、隐含平减指数和消费/收入比例仅按研究包公开输入计算，不生成新的月份或年份。
- 研究覆盖矩阵分子为“已覆盖＋部分覆盖”，分母剔除“不适用”。没有适用指标的格子显示“不适用”，不是0%的覆盖率。
- 矩阵按独立指标去重。同一指标服务多个体系不代表新增经济数据；“无稳定公开数据”仅指本轮研究缺口。
- 不提供未经证据支持的七维评级、加权总分、实时经济判断或预测。
- 每条样例都有允许与禁止作出的判断；指标详情保留统计对象、公式、来源、历史、断点和误读风险。

## 更新与构建

1. 按根目录说明更新并核验 `data/catalog.json`。
2. 在仓库根目录运行 `python3 scripts/prepare_dashboard_data.py`，保持仪表盘ID，刷新展示快照并标记更新中。
3. 运行 `node --test scripts/test_dashboard.mjs`，验证取数、公式、覆盖分母、筛选、导出和来源关联。
4. 内容与外观放在 `src/content/dashboard/` 和 `src/theme.css`。遵守 [AGENTS.md](AGENTS.md) 的编辑边界。
5. 在安装了 Codex Data 插件的环境中，使用插件的普通构建入口：

```sh
node <data-plugin-root>/scripts/data-app.mjs build --project-dir dashboard --separate-data
```

这里的命令在仓库根目录执行。`<data-plugin-root>` 是本机已安装 Data 插件路径；运行环境并非仓库附带的通用 npm 安装承诺。普通读者直接使用已提交的 `dist/` 即可。

完成内容检查后将 `src/data.json` 的 `buildStatus` 设为 `complete`，再次构建并刷新预览。整组提交 `dist` 的 HTML、内容寻址JSON和构建清单；不要混用不同次构建的文件。
